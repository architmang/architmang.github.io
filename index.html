Why does Windows block file renames or deletes while a file is open, unlike Unix?

Windows NTFS uses mandatory file locking at the kernel level. Open handles hold exclusive access. Unix takes the opposite stance: unlink the directory entry and let the inode live until the last handle closes.

What actually happens under the hood when you call malloc() on Linux?

malloc() is not a syscall. It is a user-space allocator managing memory it got from brk() or mmap(). Small allocations carve up arenas, large ones go straight to mmap, and jemalloc/tcmalloc change the whole story.

2025LinkedIn

Where does std::random_device() actually get its randomness from?

On Linux it reads /dev/urandom, seeded by the kernel entropy pool built from hardware interrupts and noise. On Windows it calls BCryptGenRandom. Neither is truly random; both are cryptographically secure PRNGs.

Security
2025LinkedIn

Why do phones require your passcode after a reboot instead of letting you use Face ID or fingerprint?

Biometrics only unlock a key already in memory. After a reboot, the secure enclave decryption keys are gone. Only your passcode can re-derive them and unseal the TPM. This is Before First Unlock protection.
